# Цифровой Рай — форма оптового заказа

Адаптивная страница магазина с каталогом Apple, расчётом количества и суммы в реальном времени и безопасной отправкой заказа владельцу через Telegram-бота.

## Что уже работает

- три товара Apple с фотографиями, артикулами и ценами;
- количество от 1 до 1 000 штук для выбранной позиции (0 — не добавлять в заказ);
- автоматический расчёт каждой строки, общего количества и итоговой суммы;
- проверка Telegram-ника покупателя;
- серверная перепроверка товаров, количества и цен;
- отправка владельцу полного списка заказа через Telegram Bot API;
- адаптивный интерфейс для компьютера и телефона;
- тесты серверной логики и Dockerfile для публикации.

## Локальный запуск

Требуется Node.js 20 или новее. Сторонние пакеты не используются.

```bash
npm start
```

Откройте `http://localhost:3000`. Без Telegram-настроек локальный сервер работает в демонстрационном режиме и печатает сформированный заказ в терминал.

## Подключение Telegram

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Напишите созданному боту любое сообщение.
3. Откройте `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` и найдите `message.chat.id`.
4. На хостинге задайте секретные переменные окружения:

```env
TELEGRAM_BOT_TOKEN=токен_бота
TELEGRAM_CHAT_ID=ваш_chat_id
```

Токен нельзя добавлять в файлы репозитория или клиентский JavaScript. В production без этих переменных сервер намеренно не принимает заказ, чтобы покупатель не получил ложное подтверждение.

## Публикация

Приложение является небольшим Node.js-сервисом и подходит для Render, Railway, Fly.io или любого VPS/Docker-хостинга.

- команда запуска: `npm start`;
- порт: переменная `PORT` (по умолчанию `3000`);
- проверка состояния: `GET /api/health`.

GitHub Pages не подходит для полной версии, потому что он не выполняет серверный код и не умеет безопасно хранить токен Telegram-бота.
